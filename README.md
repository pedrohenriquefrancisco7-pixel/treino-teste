# treino-teste
fazendo teste

## Modo 1v1 (`1v1.html`)

- **Contra Bot**: começa na hora (Fácil, Normal ou Difícil).
- **Contra Player**: cria uma sala e gera um link de convite. Para o link funcionar, a página precisa estar publicada (ex.: GitHub Pages → Settings → Pages → branch `main`). O link fica assim: `https://SEU-USUARIO.github.io/treino-teste/1v1.html?sala=xxxxxx`.

Regras: 3 vidas por rodada, tiro no peito tira 1, na cabeça tira 3. Zerou o outro, ganha 1 ponto. Primeiro a 10 vence. Contagem 3 → 0 antes de cada rodada. Pistola semiautomática (~6,7 tiros/s, pente de 12, recarga 1,75 s).

Controles: WASD andar · Shift andar devagar (tiro preciso) · Clique atirar · R recarregar · Esc pausa.
